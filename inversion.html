CORE PRINCIPLES

核心定義與萬能破題口訣

為何古人要倒裝？文言文中為了強調「客體賓語」，會特意將賓語拉到述語動作之前！

終極解題必殺技
「去掉四隻刺蝟，動前名後，喂，前面的，統統不准動！」

💡 刺蝟四兄弟：指無義的結構助詞「是」、「之」、「之為」（及「唯…是…」中的助詞標誌）。消去刺蝟後，把真正的述語動詞移回名詞賓語前面，原句前面的「唯」等副詞或主語則絕對保持原位不動！

1

去掉助詞標誌

消去無義的結構助詞：是、之、之為。這些助詞只是古人立在此處提醒讀者「這裡有賓語提前」的標籤。

刺蝟退場
2

圈出名詞賓語

找出原本作為受詞的名詞或代名詞（例如：菊、蓮、馬首、你、利、其疾）。

鎖定受詞
3

標出述語動詞

找出句子中最核心的動作述語（例如：愛、瞻、從、問、圖、憂、有）。

鎖定動作
4

動前名後歸位

將動詞大步邁向名詞前面，恢復為中文常態的「動詞 + 名詞（述語+賓語）」語序！

順序復原
5

喂！前面不動

句首的副詞（唯、不、尺璧非寶）或省略後保留的主語，統統不准動，原地保留！

副詞護法
SYNTAX STRUCTURE

雙軌句法結構星盤

透過現代句型公式對比，一目了然看穿倒裝句前後位移軌跡。

正常中文常態語序 (S + V + O)
[主語] + [述語(動詞)] + [賓語(名詞受詞)]

例句：(我) 愛 菊 / 唯 圖 利

賓語提前倒裝句型 (O + [助詞] + V)
[副詞] + [賓語提前] + [結構助詞] + [述語(動詞)]

例句：菊 之 愛 / 唯 利 是 圖

📌 老師黑板劃重點：文言倒裝句三大特質：
1. 無義助詞標誌：倒裝後常接「之」、「是」、「之為」，強調前置受詞並提醒讀者語法變化。
2. 省略主語常態：古文為求精鍊常略去「我、人」等主語（如「菊之愛」即「我愛菊」）。
3. 前置限制副詞：常在提前賓語前加上「唯」（只、僅），強化排他性的強調語氣（如「唯利是圖」＝只貪圖利益）。
